# Apex Heresy

An unofficial Foundry VTT system for the Warhammer 40,000 roleplaying games built on the
d100 percentile engine: **Dark Heresy 2nd Edition**, **Black Crusade**, **Only War**,
**Rogue Trader** and **Deathwatch**.

Each book gets its own character sheet and its own rules. A Battle-Brother does not bleed,
a Heretic answers to a patron, a Guardsman fights beside a Comrade, an Explorer counts
Profit Factor — and none of them are a Dark Heresy acolyte wearing a different label.

## Install

In Foundry, go to **Configuration → Game Systems → Install System** and paste the manifest
URL:

```
https://raw.githubusercontent.com/xalatathzx-art/Apex-Heresy/main/system.json
```

Requires Foundry VTT v14 or later.

## What it does

**Five books, five sheets.** The book is chosen when the character is created and decides
everything after: which fields the biography asks for, which figures stand in the header,
which tabs exist. A Deathwatch sheet carries Renown, Cohesion and an Oath; a Black Crusade
sheet carries Infamy where Fate would be.

**Rules read out of each book, not shared by assumption.** Fatigue, Blood Loss, Corruption,
Insanity, Righteous Fury, psychic phenomena and the Focus Power Test all branch by book,
because the books genuinely differ. The Deathwatch Purity Threshold does nothing until 100;
Black Crusade kills on a 10% roll where Dark Heresy only tires you.

**Compendium content.** Weapons, armour, gear, talents, traits, psychic powers and tables
for all five books, plus an Origins pack of home worlds, backgrounds, roles, regiments,
archetypes, Chapters and Specialities.

**Combat that does the arithmetic.** Rate of fire and jams, weapon qualities, force fields,
armour by hit location, called shots, evasion, suppression, overheat, critical effects and
conditions that actually apply their modifiers.

**Vehicles and void ships.** Vehicle combat with facings and critical hits, and ship combat
with components, crew, turns and boarding.

## Not included

The system ships no copyrighted rules text beyond what a reference tool needs. You need the
rulebooks to play.

## Reporting a problem

Open an issue at <https://github.com/xalatathzx-art/Apex-Heresy/issues>. A report that names
the book, the sheet and what you expected the rule to do is one that can be fixed.
