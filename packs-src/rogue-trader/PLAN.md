# Компендиум Rogue Trader — план переноса

Источник: `Rogue Trader - Core Rulebook (updated with 1.4 errata).pdf` (401 стр.).
Номер страницы книги = номер страницы PDF − 1. В `source` пишется номер книги.

Пак: `packs/rogue-trader`, тип Item, подпись «Rogue Trader», в папке паков
«Warhammer 40,000 Roleplay» рядом с Black Crusade и Dark Heresy.

## Как устроен перенос

- Исходники — `packs-src/rogue-trader/NN-раздел.json`, каждый файл — массив предметов.
- Дерево папок и цвета — `packs-src/rogue-trader/folders.json`.
- Сборка — `node tools/build-items.mjs`. Проверка без записи —
  `node tools/build-items.mjs --check`. Писать в пак можно только при закрытом
  Foundry (он держит LOCK); проверку — всегда.
- Идентификаторы детерминированные (sha1 от папки и имени): пересборка не рвёт
  ссылки на уже перетащенные в мир предметы.

### Запись предмета

```json
{
  "name": "Lasgun",
  "type": "weapon",
  "folder": "Ranged Weapons/Las",
  "img": "systems/dark-heresy/assets/icons/weapons/lasgun.webp",
  "system": {
    "class": "basic", "type": "las", "range": 100,
    "rateOfFire": { "single": 1, "burst": 3, "full": 0 },
    "damage": "1d10+3", "damageType": "energy", "penetration": "0",
    "clip": { "max": 60, "value": 60 }, "reload": "Full",
    "special": "Reliable", "weight": 4, "availability": "common",
    "description": "<div class=\"bc-entry\">…</div>",
    "source": "Rogue Trader, p. 118 (Table 5-4)"
  }
}
```

Недостающие поля сборщик берёт из `template.json`, лишние и опечатки — ошибка.

### Описание — книжная вёрстка, как в паке Black Crusade

```html
<div class="bc-entry">
  <p class="bc-lead">Художественный абзац из книги.</p>
  <div class="bc-rule"><p>Правило предмета дословно.</p></div>
</div>
```

Текст — дословно по книге (с учётом эррат 1.4), без пересказа.

### Соответствие полей

| Книга | Поле |
|---|---|
| Class Pistol/Basic/Heavy/Melee/Thrown | `class`: pistol / basic / heavy / melee / thrown; ракеты — launched |
| Раздел Las, SP, Bolt, Melta, Plasma, Flame, Primitive, Launcher, Exotic, Chain, Power, Shock | `type`: las / solidprojectile / bolt / melta / plasma / flame / lowtech / launcher / exotic / chain / power / shock; гранаты — explosive |
| RoF `S/3/–` | `rateOfFire`: single 1 при S, burst 3, full 0 при – |
| Dmg `1d10+3 E` | `damage` "1d10+3", `damageType` E energy · I impact · R rending · X explosive |
| Rld Half / Full / 2Full | `reload` как в книге |
| Special | `special` — каноническими именами из `DH_WEAPON_TRAITS`; качества, которых система не знает, пишутся как в книге (сборщик предупредит) |
| Availability | `availability`: ubiquitous … unique |
| kg | `weight` |
| Броня: Locations Covered + AP | `part.{head,leftArm,rightArm,body,leftLeg,rightLeg}`, `type` basic/flak/mesh/carapace/power |
| Корабельное оружие | `shipWeapon`: `weaponType` macrobattery/lance, `strength`, `critRating`, `damage`, `range`, `power`, `space`, `shipPoints`; ограничения корпуса — в описании |
| Компоненты | `shipComponent`: `category` essential/supplemental, `power` (расход), `powerGenerated` (плазменные приводы), `space`, `shipPoints`; допустимые корпуса и особые правила — в описании |

## Вне предметного компендиума

Корпуса кораблей (стр. 193–197) и готовые корабли НИП (стр. 209–211) — это
свойства актёра-корабля, а не предметы. Их место — отдельный компендиум
актёров; таблицы осложнений корпуса (Table 8-1, 8-2) — в компендиум таблиц.
Это отдельная работа после фазы 18.

## Журнал

Здесь отмечается, что сделано в каждой итерации: фаза, файл, число предметов,
расхождения с книгой.

- **Итерация 1, фаза 0.** `folders.json` — 51 папка в палитре DH (подпапки
  компонентов и психических техник — в их фазах). Пак `rogue-trader` в
  `system.json` и в папке паков. `shipWeapon.shipPoints` в схеме и на листе.
  Пробный прогон: сборщик поймал все подложенные ошибки (папка, опечатка в
  поле, нет source, неверный class), незнакомое качество — предупреждением.

- **Итерация 1, фазы 1–2.** `01-ranged-weapons.json` — 48 стволов Table 5-4
  (Las 10, SP 12, Bolt 4, Melta 5, Plasma 3, Flame 3, Primitive 7, Launchers 4).
  `02-grenades-missiles.json` — 14 записей Table 5-6. Проверка чистая, 62
  предмета. Расхождения с таблицей: плазменным стволам добавлено качество
  Maximal (в таблице его нет, но раздел «Firing Plasma Weapons» даёт его всем
  имперским плазменным), плазменной гранате проставлен тип урона «энергия»
  (в таблице буква типа пропущена).

- **Итерация 1, фазы 3–4.** `03-exotic-weapons.json` — 14 записей Table 5-7,
  `04-melee-weapons.json` — 27 записей Table 5-8 (Chain 2, Power 6, Shock 3,
  Primitive 11, Exotic 5). Оружию без урона в таблице (сети, снаряды-ловушки)
  сборщик сделан снисходительным: класс launcher/explosive/exotic и качество
  Snare урон не требуют.

- **Итерация 1, фаза 5.** `05-weapon-upgrades.json` — 15 записей Table 5-9,
  `06-ammunition.json` — 28 записей: Table 5-10 плюс Unusual Ammunition.

- **Итерация 1, фаза 6.** `07-armour.json` — 20 записей Table 5-12
  (Primitive 4, Flak 4, Mesh 4, Carapace 4, Power 2, прочее 2). Личных силовых
  полей в ядре Rogue Trader нет — папка `Force Fields` остаётся пустой, в
  фазе 18 её нужно убрать.

- **Итерация 1, фаза 7.** `08-gear.json` — 20 записей Table 5-13,
  `09-drugs.json` — 16 препаратов раздела Drugs and Consumables,
  `10-tools.json` — 37 записей Table 5-15.

- **Итерация 1, фаза 8.** `11-cybernetics.json` — 27 записей Table 5-16
  (3 бионические замены, 24 импланта); число сверено с таблицей на стр. 152.
  Броня имплантатов проведена как прибавка к надетой (`isAdditive`): черепная
  броня +1 голове, бионическое сердце +1 корпусу, подкожная броня +2 рукам,
  корпусу и ногам. «Гибельному глазу» дана атака хеллпистоля с дальностью 10 м.
  Проверка чистая, 266 предметов.

- **Итерация 1, фаза 9.** `12-starship-weapons.json` — 8 стволов Table 8-4
  (5 макробатарей, 3 ланса). В PDF строки лансов разъехались с именами; числа
  Power/Space/SP сверены по Table 8-5 на стр. 204, где те же стволы повторены.
  Допустимые корпуса и правило установки лансов на кораблях не крупнее фрегата
  — в описании, система их не проверяет. Слот выставлен по книге там, где она
  его требует (бортовая макропушка — port), остальным дан обычный dorsal/prow.

- **Итерация 1, фаза 10.** `13-essential-components.json` — 31 строка Table 8-3
  (24 компонента: приводы 5, варп-двигатели 2, поля Геллера 2, щиты 2, мостики
  5, жизнеобеспечение 2, кубрики 2, ауспексы 4). Восемь компонентов идут в
  таблице двумя строками — своя цена на эскорт и своя на крейсер; такие
  разведены в отдельные предметы с классом корпуса в имени, иначе смета корабля
  считала бы не по той строке. Плазменным приводам мощность записана в
  `powerGenerated`. В `folders.json` добавлены восемь подпапок по видам.

- **Итерация 1, фаза 11.** `14-supplemental-components.json` — 24 строки
  Table 8-5 (трюмы и каюты 5, усиления 10, службы 9). Остальные 8 строк
  таблицы — макробатареи и лансы, они уже лежат в «Starship Weapons» после
  фазы 9. Компоненты с несколькими строками по классу корпуса разведены так же,
  как в фазе 10. Сноска «не более одного на корабль» перенесена в описание
  каждого помеченного компонента.

- **Итерация 1, фаза 12.** `15-archeotech-xenotech.json` — 11 строк Table 8-6 и
  6 строк Table 8-7, всего 17. Доступность из Table 8-8 (археотех — Extremely
  Rare, ксенотех — Near Unique) дописана в описание: у корабельных компонентов
  поля доступности в схеме нет. Сноска про модифицированные приводы («описан
  один раз, применяй к обычному приводу») стоит у Jovian Class 1, но строки
  таблицы разведены по приводам — так смета считает верный объём. Shard Cannon
  Battery заведена как `shipWeapon`, а не компонент: у неё в книге полный
  профиль макробатареи, иначе с корабля ей не выстрелить.

- **Итерация 1, фаза 13.** `16-talents.json` — 147 талантов, ровно столько же
  строк в Table 4-1 (49 + 51 + 47 по трём страницам таблицы). В `prerequisites`
  стоит колонка таблицы, в `benefit` — её колонка Benefit, полный текст — в
  описании. Иконка выбрана по требуемой характеристике (WS, BS, Ag, …), у
  веры — аквила, у механикумских — шестерня.

  Шесть расхождений таблицы с текстом статьи выписаны прямо в описания:
  Blessed Radiance (Pure Faith против Purge the Unclean), Mechadendrite Use и
  три «Обряда» (Mechanicus Implants против Explorator), Polyglot (Int 30 против
  40), Prosanguine (без требований против Autosanguine), Whispers (Int 40 /
  Fel 30 против Int 45 / Fel 35). Везде в поле записано значение таблицы.

- **Итерация 1, фаза 14.** `17-psychic-techniques.json` — 35 записей: 32 строки
  таблиц 6-4, 6-7, 6-9 и 6-15 (телепатия 9 + 8, дивинация 8, телекинез 7) плюс
  три базовые техники дисциплин (Thought Sending, Aura Reading, Mind over
  Matter), которых в таблицах цен нет, но без них дисциплина не работает; им
  проставлена цена 0.

  `focusPower.test` система понимает только как характеристику или навык, так
  что у противопоставленных проверок в поле стоит Willpower, а слово Opposed —
  первой строкой правила. Ступенчатые таблицы техник (Mind Probe, Reprogram,
  Aura Reading, Augury, Psycholocation, Psychometry) перенесены в описания
  списком `bc-prof`. Урон заполнен там, где книга даёт кость: Psychic Scream,
  Force Bolt, Telekinetic Crush и Mind over Matter — bolt, Force Shards и
  Storm of Force — storm, Telekinetic Weapon — рукопашная, зона none. Прибавка
  «за очко Psy Rating» уходит в `damage.special`: числом её не записать.

- **Итерация 1, фаза 15.** `18-navigator.json` — 9 сил Навигатора из главы 7 и
  13 строк Table 7-1: Navigator Mutations. Отдельного типа предмета под силы
  Навигатора в системе нет, поэтому они заведены как `psychicPower` с подтипом
  «Navigator Power» и ценой 0: покупаются они талантом Navigator Power, своей
  цены в книге не имеют. Три ступени мастерства (Novice / Adept / Master) —
  внутри описания, поле у предмета одно. В PDF заголовки сил разъехались с
  текстом на страницу вперёд; принадлежность восстановлена по содержанию.

- **Итерация 1, фаза 16.** `19-traits.json` — 31 строка Table 14-1 плюс две
  черты, описанные в главе, но в таблицу не попавшие: Hoverer (стр. 364) и
  Mechanicus Implants (врезка на стр. 366); обе помечены в описании. Имена
  взяты по заголовкам статей, а не по таблице: Dark Sight против Dark-sight и
  Warp Weapon против Warp Weapons — расхождение выписано в описания.
  `20-mutations.json` — 29 строк Table 14-3. У таблицы опечатка: Ravaged Body
  занимает 68–71 и Clawed/Fanged 71–74, значение 71 попадает в обе строки —
  это отмечено в описании Ravaged Body. Всего 62 записи, проверка чистая.

- **Итерация 1, фаза 17.** `21-special-abilities.json` — 15 способностей со
  стр. 72 (все восемь карьер собраны на одной странице, а не по разделам, как
  предполагал план): Rogue Trader 1, Arch-Militant 1, Astropath Transcendent 3,
  Explorator 1, Missionary 1, Navigator 3, Seneschal 1, Void-master 4. У
  Пустотника все четыре «мастерства» заведены отдельными предметами — по книге
  выбирается одно. Способность миссионера названа «Pure Faith (Missionary)»,
  чтобы не столкнуться с одноимённым талантом.

- **Итерация 1, фаза 18.** Пустая папка `Force Fields` убрана из `folders.json`
  и из таблицы палитры: личных силовых полей в ядре Rogue Trader нет. Полная
  проверка чистая, пак собран при закрытом Foundry: 627 предметов, 66 папок.

  Прочитано обратно из LevelDB: у всех 627 записей есть имя, тип, папка и
  source; типы разложились как 147 талантов, 103 ствола, 71 компонент, 44
  психические силы (35 техник + 9 сил Навигатора), 42 мутации, 40 инструментов,
  33 черты, 28 боеприпасов, 27 имплантатов, 20 брони, 20 снаряжения, 15
  улучшений оружия, 15 способностей карьер, 13 препаратов, 9 корабельных
  стволов.

  Проверено в игре: пак виден как «Rogue Trader», 627 предметов и 66 папок, у
  всех 20 корневых папок свой цвет из палитры DH. Лазган и цепной меч ложатся
  на лист персонажа и целятся в нужную характеристику (45 БН и 40 БМ), урон
  бросается. Гвардейская флак-броня даёт 4 очка на все зоны — после того как её
  наденут: из компендиума вещи приходят неношеными, и это правильно.

  Корабль: восемь существенных компонентов и два ствола встали в сметы —
  мощность 37 из 45, объём 32 из 40 у корпуса фрегата. Марсианская макропушка
  и лансер «Титанфордж» стреляют с листа корабля: у макропушки попадание,
  1 удар, 9 урона корпусу. Тестовые актёры удалены.
